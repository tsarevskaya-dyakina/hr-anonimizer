# Безопасный цикл

Автономный анонимайзер Excel, Word и обычного текста. Реализованы **этапы 1–6 из 7** по техническому заданию.
Файл для пользователя: **bezopasnyj-cikl-v0.6.0.html**. Он содержит весь код и оформление, не загружает внешние библиотеки и не требует установки приложения.

**Начните с тестовых данных.** Текстовые и скрытые части Excel и Word обрабатываются и проверяются на известные исходные значения. Поиск по правилам может пропускать данные; для ключа доступна защита паролем. Готовность для реальных конфиденциальных документов и проверка службой ИБ не заявляются.

## Что работает

- Пакет до 100 файлов: единые метки, один ключ, общий сдвиг дат и необязательный общий коэффициент. Для совпадающих заголовков можно применить настройки первого листа. Готовые копии скачиваются одним ZIP без ключа.
- CSV: UTF-8 и Windows-1251, автоматический выбор разделителя, кавычки, переносы строк и ведущие нули. Сохраняются кодировка и разделитель.
- Ключ JSON или XLSX с листами «Соответствия», «Параметры» и скрытым полным ключом для возврата. По умолчанию предлагается пароль: AES-256-GCM, PBKDF2-SHA-256, 310 000 итераций. Защищённый XLSX скачивается как `.xlsx.enc` и открывается этим приложением с паролем. Пароль нельзя восстановить.
- Возврат нескольких файлов с одним ключом; при неоднозначном соответствии требуется выбрать исходный файл. Есть отдельные настройки числовых столбцов каждого файла.
- Web Worker выполняет поиск, аудит, ZIP, CSV и шифрование. Большие стандартные XML разбираются порциями через DOMParser. Доступны прогресс и отмена.

- Загрузка `.xlsx` и `.xlsm`, все табличные листы, включая скрытые и полностью скрытые.
- Настройка строки заголовков для каждого листа; просмотр пяти строк данных.
- Режимы «Псевдоним», «Удалить значения», «Оставить», «Найти в тексте», «Масштабировать», «Диапазоны», «Сдвинуть даты».
- Масштабирование числовых столбцов: случайный коэффициент от 0,6 до 1,4, свой для столбца или общий для книги. Десятичное округление учитывает исходные значения и формат; точность ограничена восемью знаками.
- Диапазоны с настраиваемым шагом. Нижняя граница включена, верхняя — нет; точные значения выбранных ячеек в ключ не записываются и не восстанавливаются.
- Единый случайный сдвиг дат на 30–365 дней вперёд или назад. Даты определяются по форматам ячеек, включая форматы строки/столбца; поддержаны системы дат 1900 и 1904, доли суток и тип даты OOXML.
- Точный возврат чисел и дат для неизменённой книги. Для изменённой книги — выбор столбцов и исходного коэффициента, включая новые расчёты ИИ. Результаты формул при обратном преобразовании сохраняются и отмечаются в отчёте.
- Загрузка `.docx`: основной текст, таблицы, колонтитулы, сноски и концевые сноски, текстовые блоки и подписи. Имена, разбитые на несколько фрагментов оформления, заменяются целиком с оформлением первого фрагмента.
- Для Word по умолчанию принимаются исправления и удаляются комментарии. Можно сохранить их структуру: удалённый текст, авторы, инициалы и people.xml также обезличиваются.
- Поля Word, включая MERGEFIELD и HYPERLINK, превращаются в видимый текст; внешние связи, свойства, customXml и вложения удаляются. Изображения сохраняются с предупреждением и блокировкой скачивания либо удаляются по настройке. OCR отсутствует.
- Точный возврат сохранённых абзацев Word с исходными фрагментами оформления при совпадении SHA-256; после редактирования — возврат по меткам, включая метки в нескольких фрагментах. Удалённая история, комментарии, свойства и коды полей не восстанавливаются.
- Поле для вставленного текста: обезличивание, копирование, скачивание `.txt` и возврат по ключу.
- Поиск ФИО и основных падежных форм, инициалы в обоих порядках. Словарь содержит 440 имён. Объединение инициалов с полным ФИО требует выбора пользователя.
- Проверки контрольных цифр ИНН, СНИЛС, банковских карт, ОГРН и ОГРНИП; поиск телефонов, e-mail и контекстных реквизитов.
- Поиск организаций в кавычках, адресов, дат рождения, номеров документов и сумм внутри текста.
- Пользовательский словарь клиентов, партнёров, продуктов и проектов, импорт/экспорт `.txt` и `.xlsx`, ручное скрытие фрагмента со своей категорией.
- Перекрёстная проверка переносит известные метки в другие текстовые ячейки, включая столбцы «Оставить». Её можно отключить.
- Единые метки внутри книги для одинаковых значений одной категории. При сопоставлении игнорируются внешние пробелы, регистр и различие е/ё.
- Перемешивание нумерации; защита от совпадения меток с похожим исходным текстом.
- Единые метки в примечаниях, авторах обсуждений, колонтитулах, списках выбора, заголовках таблиц, именованных диапазонах, надписях фигур и текстах диаграмм. Заголовки таблиц согласуются с ячейками и структурными ссылками формул.
- Кэши формул, числовых диаграмм и сводных таблиц очищаются; включается пересчёт. Индексы элементов кэша сводной сохраняют позиции. Внешние пути заменяются заглушкой, автоматическое обновление отключается.
- В Excel свойства файла, гиперссылки, изображения, вложения, пользовательские XML и настройки устройств удаляются без восстановления. OCR отсутствует.
- Проверка всех XML/REL/VML-частей, в том числе неизвестных расширений, на исходные значения из ключа и известные падежные формы. Отчёт указывает часть и доступное место, в Word — номер абзаца; непроверенные двоичные части и внешние формулы блокируют скачивание до явного выбора «Скачать всё равно».
- «Проверьте глазами»: слова с заглавной буквы внутри предложения, длинные номера и похожие на e-mail фрагменты. Каждого кандидата можно скрыть одним нажатием с повторной обработкой исходника.
- Предпросмотр изменений в первых 20 строках листа.
- Скачивание копий `_anon.xlsx`, `_anon.xlsm`, `_anon.csv`, `_anon.docx` или ZIP пакета и отдельного ключа `.json`/`.xlsx` с отпечатком SHA-256.
- Возврат по содержимому ячеек. Для неизменённой копии восстанавливаются точные варианты написания и типы; в изменённом файле возвращается основное значение из ключа.
- Встроенный вымышленный пример Word «Служебная записка» и 29 самопроверок.
- Проверка структуры архива и контрольных сумм, понятные ошибки повреждённых файлов.

Удаление очищает значения ниже заголовка, оставляя структуру и оформление. Значения удалённых столбцов в ключ не попадают и не восстанавливаются. Изменение столбцов с формулами, включая области результатов общей формулы, блокируется. Выражения формул сохраняются; старые результаты очищаются, а остаточные исходные значения в выражениях попадают в отчёт. Повторы удалённых значений и исходных чисел выбранных преобразований очищаются в поддержанных текстах. Неизвестные части проверяются, но не исправляются автоматически.

## Как пользоваться

Скачайте HTML на компьютер и откройте в современном браузере. Открытие двойным щелчком в этой облачной среде не проверено из-за политики Chromium; его нужно проверить на вашем компьютере. Нажмите «Попробовать на примере» или «Пример чисел и дат», «Пример скрытых частей» или выберите «Документ Word» → «Пример Word». Подробности: [отчёт этапа 6](STAGE-6-REPORT.md), [отчёт этапа 5](STAGE-5-REPORT.md), [инструкция](INSTRUCTION.md), [ограничения](LIMITATIONS.md), [отчёт этапа 4](STAGE-4-REPORT.md), [отчёт этапа 3](STAGE-3-REPORT.md), [отчёт этапа 2](STAGE-2-REPORT.md), [отчёт этапа 1](STAGE-1-REPORT.md).

Контрольная сумма файла: `bezopasnyj-cikl-v0.6.0.html.sha256`. В Linux/macOS проверить её можно командой `sha256sum -c bezopasnyj-cikl-v0.6.0.html.sha256`; в PowerShell — `Get-FileHash .\bezopasnyj-cikl-v0.6.0.html -Algorithm SHA256`.

## Для разработки

Самому приложению зависимости не нужны. Для независимых проверок используются Python, Playwright, openpyxl, XlsxWriter, python-docx и cryptography. Браузер Chromium и LibreOffice нужны для соответствующих интеграционных проверок.

В подготовленной облачной среде:

```sh
cd /workspace/hr-anonimizer
/workspace/.venv-hr-anonimizer/bin/python -m unittest discover -s tests -v
```

В другой среде:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python -m unittest discover -s tests -v
```

Если установлен системный Chromium, тесты используют его. Другой путь можно задать переменной `CHROMIUM_PATH`. Для проверок этапов 4–6 требуется LibreOffice; предыдущие сценарии при его отсутствии отмечают пропуск. Тестовый сервер запускается автоматически только на loopback-адресе и останавливается после тестов. Все тестовые данные вымышленные и размещаются во временном каталоге.
