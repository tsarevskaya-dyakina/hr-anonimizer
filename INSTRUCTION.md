# Безопасный цикл — инструкция

Начните с учебных данных. Проверяйте результат глазами: поиск по правилам может пропускать сведения.

1. Сохраните `bezopasnyj-cikl-v1.0.0.html` и откройте в современном браузере. Приложению не нужны интернет, сервер и установка. Двойной щелчок проверьте на своём компьютере: облачный Chromium запрещает здесь `file://`. **«Учебный пакет: Excel, Word и CSV»** показывает 50 вымышленных сотрудников, отпуска, записку и CSV. Подтвердите однозначные варианты ФИО, затем обработайте пакет.

2. Выберите один или несколько `.xlsx`, `.xlsm`, `.docx`, `.csv` либо **«Обычный текст»** и вставьте текст. Пакет использует общие метки и один ключ. CSV автоматически определяет кодировку и разделитель. Ошибки отдельных файлов показываются отдельно; они не входят в результат. Макросы сохраняются без проверки: не включайте их без проверки службы ИБ.

3. Для таблиц проверьте строку заголовков и режимы:

| Режим | Результат |
| --- | --- |
| Псевдоним | Значение заменяется меткой категории. |
| Найти в тексте | Заменяются найденные фрагменты. |
| Масштабировать | Числа умножаются на коэффициент 0,6–1,4. |
| Диапазоны | Числа становятся интервалами; необратимо. |
| Сдвинуть даты | Общий сдвиг выбранных дат пакета на ±30–365 дней. |
| Оставить | Известные повторы могут заменяться. |
| Удалить значения | Значения и найденные повторы очищаются без возврата. |

Для одинаковых заголовков можно применить настройки первого листа. Общий коэффициент помогает сравнивать столбцы разных файлов; округление может менять пропорции. В CSV нужны ISO-даты и числа без ведущих нулей для преобразований. Столбцы с формулами не преобразуются.

В Word по умолчанию принимаются исправления и удаляются комментарии. Картинки сохраняются с предупреждением или удаляются по настройке. OCR отсутствует; поля становятся текстом.

4. Добавьте собственные названия в **«Словарь и ручное скрытие»**. Доступны импорт/экспорт `.txt` и `.xlsx`, точный фрагмент и категория. Объединение инициалов требует вашего подтверждения.

5. Создайте копии. Проверьте цветной предпросмотр, неизменённые значения по переключателю, отчёт и **«Проверьте глазами»**. Можно скрыть кандидат и повторить обработку. Остатки и непроверенные части блокируют скачивание; **«Скачать всё равно»** принимает риск. Обработку можно отменить.

6. Подтвердите просмотр и скачайте копии или их общий архив и отдельный ключ JSON/XLSX. Защита ключа паролем предложена по умолчанию; минимум восемь символов. Защищённый XLSX имеет расширение `.xlsx.enc`. **Ключ содержит настоящие данные: никогда не отправляйте его ИИ.** Пароль нельзя восстановить. Сохраните исходники. **Комплект для хранения** содержит защищённый ключ: не передавайте весь комплект ИИ. Кнопка копирования инструкции для ИИ предлагает сохранять метки без изменений.

7. На вкладке **«Вернуть данные»** выберите ключ, введите пароль и загрузите ответы ИИ либо вставьте текст. При неоднозначности выберите исходник. Проверьте числовые столбцы и коэффициенты новых расчётов. Поддерживаются регистр, сокращённые номера и основные падежные формы стандартных меток; неизвестные остаются без замены. Проверьте падежи возвращённых имён.

Удалённые части, свойства, ссылки и диапазоны не восстанавливаются. В неизменённой копии возвращаются сохранённые точные значения и оформление.

Для службы ИБ доступны 33 самопроверки. **«Очистить сессию»** очищает данные и пароли вкладки; скачанные файлы остаются на диске.
