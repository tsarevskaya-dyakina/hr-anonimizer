# Безопасный цикл — инструкция этапа 6

Начните с учебных данных. Проверяйте результат глазами: поиск по правилам может пропускать сведения.

1. Сохраните `bezopasnyj-cikl-v0.6.0.html` и откройте в современном браузере. Интернет и установка приложения не нужны. Двойной щелчок проверьте на своём компьютере: облачный Chromium запрещает здесь `file://`. Доступны примеры Excel, скрытых частей, чисел и дат и **«Пример Word»**.

2. Выберите один или несколько `.xlsx`, `.xlsm`, `.docx`, `.csv` либо **«Обычный текст»** и вставьте текст. В пакете одинаковые люди и названия получают общие метки; ключ будет один. CSV автоматически определяет кодировку и разделитель. Макросы сохраняются без проверки: не включайте их без проверки службы ИБ.

3. Для таблиц проверьте строку заголовков и режимы:

| Режим | Результат |
| --- | --- |
| Псевдоним | Значение заменяется меткой категории. |
| Найти в тексте | Заменяются найденные фрагменты. |
| Масштабировать | Числа умножаются на коэффициент 0,6–1,4. |
| Диапазоны | Числа становятся интервалами; необратимо. |
| Сдвинуть даты | Общий сдвиг выбранных дат пакета на ±30–365 дней. |
| Оставить | Известные повторы могут заменяться. |
| Удалить значения | Значения и найденные повторы очищаются без возврата. |

Для одинаковых заголовков можно применить настройки первого листа. Общий коэффициент нужен для сравнения столбцов разных файлов; округление может менять пропорции. В CSV даты должны иметь вид ГГГГ-ММ-ДД, числа с ведущими нулями оставляйте текстом. Столбцы с формулами не преобразуются.

В Word по умолчанию принимаются исправления и удаляются комментарии. Картинки сохраняются с предупреждением или удаляются по настройке. OCR отсутствует. Поля становятся видимым текстом.

4. Добавьте собственные названия в **«Словарь и ручное скрытие»**. Доступны импорт/экспорт `.txt` и `.xlsx`, точный фрагмент и категория. Объединение инициалов с полным ФИО требует вашего выбора.

5. Создайте копии. Проверьте предпросмотр, отчёт и **«Проверьте глазами»**. Можно скрыть кандидат и повторить обработку. Известные остатки и непроверенные части блокируют скачивание; **«Скачать всё равно»** принимает риск. Большую обработку можно отменить.

6. Подтвердите просмотр, скачайте копию или ZIP пакета и отдельный ключ JSON/XLSX. По умолчанию предлагается защита паролем; задайте минимум восемь символов. Защищённый XLSX имеет расширение `.xlsx.enc`. **Ключ содержит настоящие данные: никогда не отправляйте его ИИ.** Сохраните пароль отдельно: восстановить его нельзя. Сохраните исходники.

7. На вкладке **«Вернуть данные»** выберите ключ, введите пароль, если нужен, и загрузите файлы ответа ИИ либо вставьте текст. При неоднозначности выберите исходный файл. Проверьте числовые столбцы каждого файла и коэффициенты новых расчётов. После редактирования проверьте падежи и неизвестные метки.

Удалённые части, свойства, ссылки и диапазоны не восстанавливаются. В неизменённой копии возвращаются сохранённые точные значения и оформление; ZIP не обязан совпадать побайтово.

Для службы ИБ доступны 29 самопроверок. **«Очистить сессию»** очищает данные вкладки и пароли; скачанные файлы остаются на диске.
