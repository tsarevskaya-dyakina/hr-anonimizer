Создан автономный `bezopasnyj-cikl-v0.3.0.html`. Добавлены числовые режимы Excel и обратные преобразования. Возможности этапов 1–2 сохранены; старые HTML и контрольные суммы не изменены. Разработка этапа 4 и следующих этапов не выполнялась.

## Что добавлено

- **Масштабировать**: числовые значения умножаются на случайный коэффициент 0,6–1,4, который хранится в ключе. Пользователь выбирает отдельный коэффициент для каждого столбца или общий для всей книги. Значение 1 исключено, чтобы преобразование не оказалось пустым. Коэффициенты выбираются через `crypto.getRandomValues` без смещения распределения.
- **Диапазоны**: положительный настраиваемый шаг, по умолчанию 50 000. Пример: 175 000 → «150–200 тыс.». Нижняя граница включена, верхняя исключена; для отрицательных значений используется математическое округление вниз. Исходные значения ячеек диапазонов в ключ не записываются. Возврат сообщает о необратимости и оставляет интервалы.
- **Сдвинуть даты**: одно случайное число дней для всех выбранных столбцов и листов, от 30 до 365 вперёд или назад. Даты определяются по обычным и пользовательским форматам из `styles.xml`, включая формат строки/столбца; поддержаны системы 1900 и 1904, доли суток и ячейки типа OOXML `d`.
- Десятичная арифметика чисел через BigInt. Округление половин выполняется от нуля, точность учитывает формат и исходные значения столбца, максимум восемь знаков. Числовой тип и формат ячейки сохраняются; текстовые коды, даты и длительности не масштабируются.
- Точный возврат для неизменённой копии: исходные числовые ячейки хранятся в JSON-ключе, поэтому потери от округления обратимы в этом сценарии. Типы, значения и стили возвращаются точно; диапазоны являются исключением.
- Для изменённой книги — список числовых столбцов, выбор обратного преобразования и коэффициента исходного столбца. Заголовки сопоставляются независимо от позиции и имени листа. Повторяющиеся заголовки с общим коэффициентом сопоставляются автоматически; разные коэффициенты требуют выбора пользователя. Для новых расчётов ИИ выбор выполняется вручную.
- Результаты формул при числовом возврате не преобразуются; формулы сохраняются и пропуски попадают в отчёт. Для исходной анонимизации столбцы с формулами и области общей формулы остаются защищёнными.
- Учебный пример чисел и дат и четыре новые встроенные самопроверки. В предпросмотре даты показываются в читаемом виде.

## Ограничения

**Версия предназначена для учебных данных.** Полная очистка скрытых частей и сквозной поиск утечек — этап 4. Комментарии, свойства, рисунки, кэши, формулы и другие сопутствующие части могут содержать исходные значения. Прохождение тестов этапа 3 не означает готовность к передаче реальных конфиденциальных данных.

После пересохранения или изменений файла точность обратного деления ограничена округлением. Пропорции и суммы при масштабировании сохраняются с этой погрешностью; между столбцами нужен общий коэффициент. Знание исходной суммы может раскрыть коэффициент: одно масштабирование не обеспечивает полноценной анонимности. Для неизменённой копии исходные числа возвращаются точно из ключа.

Диапазоны необратимы и становятся текстом. Они могут нарушить связанные расчёты. Столбцы с формулами не преобразуются при исходной анонимизации; формулы, зависящие от изменённых значений, требуют проверки после пересчёта. Результаты формул в изменённом файле при обратном числовом преобразовании сохраняются с предупреждением.

Текстовые даты и длительности без календарной даты не сдвигаются. Необычные форматы могут потребовать пересохранения. Перемена системы дат в возвращённой книге не поддерживается для обратного сдвига. Числовые преобразования применяются к столбцам Excel; в обычном тексте остаются детекторы и метки этапа 2.

Word — этап 5. Пакет, CSV, Web Worker, ключ `.xlsx` и шифрование — этап 6. Ключ JSON по-прежнему содержит исходные значения и секретные коэффициенты в открытом виде; его нельзя отправлять в ИИ.

Открытие через `file://` не проверено: политика облачного Chromium запрещает такой запуск. Проверки использовали временный сервер на loopback-адресе, который остановлен после тестов; приложение не зависит от сервера. Microsoft Excel, МойОфис и другие браузеры здесь не проверены.
