## Результат повторной проверки

Исходные 15 проверок прошли повторно. Дополнительные сценарии обнаружили две ошибки, которые исправлены:

- Формула массива хранится только в первой ячейке области. Остальные ячейки раньше можно было заменить или очистить, после чего пересчёт Excel мог восстановить результаты формулы. Теперь при выборе затронутого столбца обработка блокируется; общая формула и исходный файл не меняются. Такая же защита применяется при возврате меток из области формулы.
- После окончания операции категория метки становилась доступной для режимов «Оставить» и «Удалить». Теперь доступность соответствует выбранному режиму и сохраняется после самопроверки.

Также проверена отмена: незавершённый результат не публикуется в интерфейсе, кнопки скачивания остаются недоступными, повторный запуск успешно обрабатывает исходный пример. В новых сценариях скорректированы ожидание количества замен и открытие свёрнутого раздела; ожидание завершения операции выполняется через состояние элементов, без запрещённого CSP вычисления строк JavaScript.

Контрольная сумма HTML обновлена. Версия формата ключа сохранена: эти исправления не требуют нового формата ключа.
