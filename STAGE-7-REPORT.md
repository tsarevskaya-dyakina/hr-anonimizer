# Итоговый выпуск — Безопасный цикл 1.0.0

Дата: 07.10.2026. Приложение: [bezopasnyj-cikl-v1.0.0.html](bezopasnyj-cikl-v1.0.0.html). Разработка всех семи этапов технического задания завершена.

## Что изменилось

- Русский интерфейс с четырьмя шагами, системной светлой/тёмной темой, подписями полей, переключением вкладок с клавиатуры и ссылкой перехода к рабочей области. Предпросмотр показывает первые 20 строк листа; неизменённые значения доступны по переключателю. Цвета меток сопровождаются названиями категорий. Служебные пути частей документа вынесены в раскрываемые подробности.
- Значок автономной работы и инструкция проверки без интернета. Кнопка инструкции для ИИ предлагает сохранять метки без склонения и попыток расшифровки; если буфер обмена недоступен, текст можно выделить и скопировать вручную.
- Учебный пакет из четырёх файлов с 50 вымышленными сотрудниками. В книге «Сотрудники» есть ведущие нули, скрытые оклады, примечание, автор, настоящие диаграмма и сводная таблица, формула суммы. «Отпуска» использует инициалы тех же людей. Word содержит падежи ФИО, реквизиты, клиента из словаря, колонтитулы, комментарии, исправления и слово в нескольких фрагментах оформления. CSV использует Windows-1251 и разделитель `;`. Объединение однозначных ФИО выполняется после явного подтверждения.
- Возврат понимает `[Сотруднику_0001]`, `сотрудник_1`, другой регистр и основные падежные формы стандартных категорий. Неизвестные и неоднозначные варианты остаются без замены. Похожие исходные обозначения резервируют номера меток. В неизменённом документе применяется точное сопоставление, чтобы не менять исходные обозначения.
- Отдельное скачивание файлов пакета и общий архив копий без ключа. Дополнительный комплект для хранения содержит только защищённый ключ, явно помеченный как запрещённый к передаче ИИ. Комплект нельзя создать с открытым ключом или коротким паролем.
- Повреждённый входной файл не мешает загрузке и возврату исправных файлов; исключения перечисляются в отчёте. Ошибочные настройки и конфликты с формулами по-прежнему требуют исправления.
- Изменение ключа, ответа ИИ или числовых настроек сразу отменяет прежний результат возврата. Отложенная подготовка настроек больше не скрывает готовый результат. Тяжёлые проходы по скрытым частям большой книги выполняются порциями.

Внешние запросы и ошибки консоли проверяются браузерными сценариями; намеренный запрос в отдельной странице блокируется CSP до отправки.

Проверка на 100 000 строк XLSX проходит загрузку, обезличивание, возврат и чтение результата; сверяются все имена и коды с ведущими нулями, количество замен и отсутствие известных остатков. Отдельный сценарий CSV на 100 000 строк проверяет обработку, ведущие нули и отзывчивость. Измерения относятся к этому экземпляру среды, не обещают такую же скорость на любом устройстве.

## Границы проверки

Использованы Chromium 151, openpyxl 3.1.5, XlsxWriter 3.2.9, Playwright 1.62.0, python-docx 1.2.0, cryptography 50.0.0 и LibreOfficeDev 26.8.0.0.alpha0. Microsoft Excel/Word, МойОфис и остальные браузеры не проверены. Загрузка Firefox/WebKit для дополнительных проверок остановлена политикой сети: серверы Playwright вернули HTTP 403 «Domain forbidden». Прямое открытие `file://` запрещено политикой облачного Chromium; тесты использовали временный loopback-сервер. Пользователь должен проверить двойной щелчок на своём компьютере.

Поиск по правилам требует проверки человеком. OCR и аудит макросов отсутствуют. Неизвестные и двоичные части могут блокировать скачивание. Удаление, диапазоны, очищенные свойства, ссылки, вложения и история не восстанавливаются. Имена файлов не обезличиваются автоматически. Подробности: [LIMITATIONS.md](LIMITATIONS.md).

Ключ содержит настоящие данные даже при защите паролем: его и весь комплект для хранения нельзя передавать ИИ. Пароль не восстанавливается. Поддерживаются прежние JSON-ключи 0.1.0–0.6.0 и пакетные ключи 0.6.0; новые ключи не предназначены для старых выпусков HTML.

Инструкция: [INSTRUCTION.md](INSTRUCTION.md), 456 слов. Исторические HTML-выпуски сохранены. Обновлённые инструкции запуска сохранены в черновик настроек среды; скрипт установки, сеть и список репозиториев сохранены без изменений. Для применения пользователь проверяет и сохраняет настройки, затем публикует среду. Восстановление среды в новой задаче отдельно не проверено.
